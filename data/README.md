# Data

Raw Twitter support data is intentionally not committed to the repository.

## Primary dataset

Kaggle: `thoughtvector/customer-support-on-twitter`

Expected workflow:

1. Download the dataset locally.
2. Place raw files under `data/raw/`.
3. Run the preparation pipeline once it is implemented.
4. Keep the final 150–250 example golden set under version control only after manual labelling and review.

The final README will document the exact file names, sample size, and commands used for reproduction.
