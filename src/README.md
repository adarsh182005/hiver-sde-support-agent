# Source

Planned modules:

- `ingest.py` — load and validate the sampled dataset
- `preprocess.py` — clean tweets and reconstruct conversations
- `sample_brand.py` — compare brands and select the evaluation brand
- `build_intents.py` — support intent taxonomy utilities
- `retrieval.py` — retrieve historically similar resolved cases
- `classifier.py` — intent classification
- `reply_generator.py` — evidence-grounded reply drafting
- `escalation.py` — auto-handle vs human escalation decision
- `agent.py` — end-to-end orchestration
